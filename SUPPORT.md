# SwiftCoder Support

Use GitHub issues for reproducible bugs and narrowly scoped feature requests.
Include the SwiftCoder version, macOS version, account plan, expected behavior,
actual behavior, and minimal reproduction steps. Remove access tokens, source
code that cannot be shared, customer data, and other sensitive information from
logs and screenshots.

Community support is best effort and has no guaranteed response time. SwiftScale
commercial support terms, if applicable to an account, are governed separately.

Security vulnerabilities must be reported privately as described in
`SECURITY.md`, not through a public support issue.
