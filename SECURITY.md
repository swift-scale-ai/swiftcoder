# Security Policy

## Supported Versions

Security fixes are provided for the latest published SwiftCoder release. Users
should upgrade to the latest available version before reporting an issue that
only affects an older build.

## Reporting A Vulnerability

Do not open a public issue for a suspected vulnerability or include credentials,
tokens, customer data, or exploit details in public discussions.

Report security issues privately through the SwiftScale contact form at
<https://swift-scale.com/contact/> and identify the report as a SwiftCoder
security issue. Include the affected version, platform, reproduction steps,
impact, and any suggested mitigation. Use temporary test credentials only.

SwiftScale will acknowledge the report through the contact information supplied
by the reporter and coordinate disclosure after a fix is available.
